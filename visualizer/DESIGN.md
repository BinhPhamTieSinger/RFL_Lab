# Design system

The workbench uses IBM Plex Sans, self-hosted through the installed font package. Terminal output and recorded values use system monospace. The primary surface is an operating tool with a central topology, a configuration rail and an inspection rail. The layout collapses into a vertical sequence on narrow screens.

Dark tokens are #111111 background, #171717 surfaces, #eeeeee text and #aaaaaa secondary text. Light tokens are #ffffff background, #f7f7f7 surfaces, #171717 text and #626262 secondary text. Grayscale outlines, double borders, dashed edges and explicit labels communicate states.

The owner supplied the direction and authorized independent implementation. Impeccable initialization uses that brief. UI UX Pro Max's search returned a marketing layout with orange accents and neumorphism. Those suggestions conflict with the brief. Its accessibility, focus, responsive-layout and chart-label guidance is applied instead.

All computation status comes from recorded events. Layout and theme controls remain available during execution. The terminal clear control affects only the current view. Heavy terminal code loads on the client.

The November 16 request authorizes green for honest clients, red for malicious clients and original colors for real CIFAR-100 sample photographs. Other interface elements remain neutral.
