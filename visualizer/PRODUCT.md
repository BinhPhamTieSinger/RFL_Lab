# Product

## Platform
web

## Stack
The owner specifies Next.js, React, TypeScript, React Flow, Tailwind, Framer Motion, Recharts, KaTeX, xterm.js and FastAPI.

## Users and purpose
Federated learning researchers inspect the actual RFL Lab implementations, configure controlled experiments and investigate recorded computations.

## Operating context
Local workstation with existing CIFAR-100 data. Ten research methods and their configured attacks execute in Python. Persist events and outcomes for review.

## Constraints
Preserve research algorithms and Git history. Use only neutral grayscale. Use professional readable typography. Respect reduced motion. Intermediate values require actual capture. The owner explicitly delegates ordinary design decisions and requests sole-agent implementation.

## Assumptions
The first deployment is loopback-only on one workstation. Shared remote hosting and authentication require further deployment work.
