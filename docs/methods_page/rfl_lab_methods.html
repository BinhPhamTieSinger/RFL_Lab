Setting and model

15 clients share CIFAR-100 (10,000 training and 3,000 test images), split by a Dirichlet(α) label partition: α = 0.5 is moderately non-IID, α = 0.05 very non-IID. Training runs 30 rounds of 5 local epochs, with 3 groups called parents. Unless stated, exactly 3 of the 15 clients attack; the authors' rule instead makes each client an attacker with probability q.

Every FedHEP variant uses one ResNet-9 trunk with three classifier heads. Which aggregation a head goes through is what makes FedHEP hierarchical.

flowchart LR
  X["image 32×32×3"] --> B["ResNet-9 trunk (each conv: 3×3 + BatchNorm + ReLU)<br/>prep 32 → 64 + max-pool + residual block<br/>→ 128 + max-pool → 256 + max-pool + residual block<br/>→ global average pool → 256 features"]
  B --> R["root head fc2_root (256 → C)<br/>aggregated by Global: shared by all"]
  B --> P["parent head fc2_parent (256 → C)<br/>aggregated within the client's group"]
  B --> L["local head fc2_local (256 → C)<br/>never leaves the client"]
  R --> E["ensemble: softmax-weighted mix of the 3 heads' logits<br/>+ mask of classes the client never saw"]
  P --> E
  L --> E
  E --> Y["prediction"]
Label skew of client i: \[ r_i = \frac{e^{H(y_i)} - 1}{C - 1} \] 1 for uniform labels, 0 for a single class (H = label entropy, C = 100).

FedHEP: one round

Each client starts from the Global model, its group's parent head and its own local head, trains, and sends its model up two paths: to Global (everyone) and to its parent (its group).

flowchart LR
  G["Global model<br/>(trunk + all heads)"] -->|"copy"| C1["client i: trunk + root head<br/>+ its parent's head + own local head"]
  C1 -->|"5 local epochs<br/>loss = λr·L_root + λp·L_parent + λl·L_local"| U["trained model w_i"]
  U -->|"all clients"| AG["Global = start + FedAvg(w_i − start)"]
  U -->|"members of group g"| AP["Parent g: copy Global if members agree<br/>(mean cosine > 0.5), else average members;<br/>adaptive momentum"]
  U -->|"kept on the client"| L["local head"]
  AG --> G
  AP --> PH["parent head for next round"]
  U --> GR["grouping: k-means on random projections<br/>of the updates (regroups when groups drift)"]
Head loss weights (binomial schedule), with \(a = \max(\tfrac{1}{2K}, |Y_i|/C)\): \[ \lambda_{local} = (1-r)^2, \qquad \lambda_{parent} = 2r(1-r), \qquad \lambda_{root} = a + (1-a)\,r^2 \] Prediction mixes the heads' logits zh: \[ p = \mathrm{softmax}\Big(\sum_h \omega_h z_h\Big), \qquad \omega = \mathrm{softmax}\big((-H_h - \beta\,\ell_h + \log \alpha_h)/T\big) \] with Hh the head's prediction entropy, ℓh its recent training loss and α a learned prior. Clients with near-uniform labels use the root head only; classes a client never saw are masked out.

Found in Phase 1: the grouping cosine is computed on the full model state, where BatchNorm's batch counters dominate, so in practice every parent copies Global every round.

Defended FedHEP (the authors' defense)

Every aggregation, at the parents and at Global, becomes SCCF (soft-cosine consensus filtering), with a trust ledger on top. Groups are random and fixed.

flowchart LR
  U["updates Δ_i of the senders"] --> NB["norm bound: scale each Δ_i to ≤ k × lower-quartile norm<br/>(k = 2 parents, 3 Global)"]
  NB --> RH["signal = root-head rows of the classes i holds"]
  RH --> REF["reference = mean of unit vectors"]
  REF --> W["trust w_i = softmax(cos(Δ_i, ref) / T)<br/>T = 0.5 (×0.9 if cosines vary, ×1.05 otherwise)"]
  W --> HR["Global only: w_i = 0 if cos < −0.1"]
  HR --> AGG["step = Σ w_i Δ_i ; BatchNorm buffers: coordinate median"]
  W --> TL["trust ledger: score_i ← 0.85·score_i + 0.15·min(1, N·w_i)<br/>isolate for good if score_i < 0.25"]
\[ \tilde\Delta_i = \Delta_i \cdot \min\Big(1, \frac{k\,Q_1(\|\Delta\|)}{\|\Delta_i\|}\Big), \qquad \bar u = \frac1N\sum_j \frac{\tilde\Delta_j}{\|\tilde\Delta_j\|}, \qquad w_i = \mathrm{softmax}_i\Big(\frac{\cos(\tilde\Delta_i, \bar u)}{T}\Big) \] \[ \text{step} = \sum_i w_i \tilde\Delta_i, \qquad \text{score}_i \leftarrow 0.85\,\text{score}_i + 0.15\min(1, N w_i), \qquad \text{isolate if score}_i < 0.25 \] k = 2 at parents and 3 at Global; T = 0.5, tightened ×0.9 when cosines vary and relaxed ×1.05 otherwise. Cosines use only the root-head rows of the classes a client holds. If \(\|\bar u\| < 0.2\) (no consensus), everyone gets \(w_i = 1/N\).

Phase 2: the ledger never isolates anyone. Attackers keep 0.5–0.8 of an equal share, so their score never falls below 0.25, and the weights flatten late in training.

FedHEP+ (Phase 3): what changes

SCCF aggregation stays. The trust ledger is replaced by screening, which decides who enters both tiers, and groups are re-formed by the similarity of the weights alone, with BatchNorm buffers left out.

flowchart TD
  T["all clients train (as FedHEP)"] --> S["score s_i = cos(Δ_i, median update) on root-head rows<br/>(non-isolated clients only)"]
  S --> Z["robust z_i (formula below)"]
  Z --> LO{"z_i < −2.5 ?"}
  LO -->|yes| OUT["left out this round"]
  Z --> EV["evidence E_i ← 0.7·E_i + 0.3·z_i"]
  EV --> ISO{"E_i < −1.5 ?"}
  ISO -->|yes| PERM["isolated for good"]
  LO -->|no| KEEP["kept"]
  KEEP --> RG["regroup kept clients by weight similarity"]
  RG --> SC["parents and Global: SCCF over kept clients"]
With \(s_i = \cos(\tilde\Delta_i, \operatorname{median}_j \tilde\Delta_j)\) on the root-head rows: \[ z_i = \frac{s_i - \operatorname{med}(s)}{\max\big(1.4826\cdot\mathrm{MAD}(s),\; 0.1\,|\operatorname{med}(s)|\big)}, \qquad \mathrm{MAD}(s) = \operatorname{med}_j |s_j - \operatorname{med}(s)| \] \[ \text{leave out this round if } z_i < -2.5, \qquad E_i \leftarrow 0.7\,E_i + 0.3\,z_i, \qquad \text{isolate for good if } E_i < -1.5 \]
  • Why 1.4826·MAD: it estimates a standard deviation from the middle of the data, so a few attackers cannot inflate it. A plain standard deviation grows with them and hides them.
  • Why a z-score: it is unchanged when every cosine shrinks together late in training. That shrinking is what made Defended FedHEP's fixed temperature and fixed 0.25 cut fade.
  • The floor 0.1·|median| stops a very tight consensus from turning tiny differences into huge z. Fewer than 5 senders are not screened.
  • Evidence: one bad round is not enough. Two rounds at z = −3 give E = −1.53.

Follow-up screening (2026-11-12)

Two options, both off by default, plus per-round logging of the raw scores, median, MAD and which term set the scale.

flowchart TD
  S["scores s_i = cos(signal_i, median update)"] --> M["median m, MAD over the reference clients"]
  M --> SC["scale = max(1.4826·MAD, 0.1·|m|, mad_floor)<br/>mad_floor = 0 (old), 0.01 or 0.03 (follow-up)"]
  SC --> Z["z_i = (s_i − m) / scale"]
  Z --> LOG["logged every round (follow-up): s, m, MAD, scale,<br/>which term set the scale, reference size"]
  Z --> EX{"z_i < −2.5 for exclusion_patience<br/>rounds in a row?"}
  EX -->|yes| OUT["left out this round"]
  Z --> EMA["E_i ← 0.7·E_i + 0.3·z_i"]
  EMA --> ISO{"E_i < −1.5 and z_i < −1.5 for<br/>isolation_patience rounds in a row?"}
  ISO -->|yes| PERM["isolated for good"]
\[ \text{scale} = \max\big(1.4826\cdot\mathrm{MAD}(s),\; 0.1\,|\operatorname{med}(s)|,\; f_{abs}\big) \] with the absolute floor \(f_{abs} \in \{0, 0.01, 0.03\}\). Patience k: isolate only when \(E_i < -1.5\) and \(z_i < -1.5\) in each of the last k rounds.

Why honest z-scores get extreme

The professor asked why the MAD shrinks and z drops. The historical runs did not log raw scores, but two logged quantities identify the mechanism across all 15 FedHEP+ runs:

  • Which term set the scale. Without the floor, the MAD of a round's z-scores is exactly 1/1.4826 = 0.674. A smaller value means the floor set the scale that round.
  • The spread of cosines. SCCF's weights are softmax(c/T), so T·ln w recovers each cosine up to a constant. This is a proxy: SCCF uses a mean-direction reference rather than the median.

The MAD does not shrink; the consensus does. The floor sets the scale in rounds 1–13. As each client's update follows its own data, the spread of cosines doubles and the median cosine falls. In rounds 14–18 the floor stops binding in every run, and false isolations peak in exactly those rounds. The fix to test is a floor that does not fall with the median.

  A["early rounds: honest updates agree<br/>median cosine high"] --> B["floor 0.1·|median cos| > 1.4826·MAD<br/>→ the floor sets z's scale (85–100% of runs, rounds 1–13)"]
  B --> C["z stays small: few false isolations"]
  A --> D["training goes on: each client's update follows its own data<br/>(non-IID drift), cosine spread doubles 0.055 → 0.12"]
  D --> E["median cosine falls → the relative floor falls with it"]
  E --> F["rounds 14–18: 1.4826·MAD takes over as the scale"]
  F --> G["persistently atypical honest clients (more skewed labels)<br/>reach z < −2.5 / E < −1.5 → false isolations peak (7 at round 14)"]
  G --> H["each removal changes the kept population<br/>and the next round's median and MAD"]
  D --> I["rounds 27–30: no consensus left<br/>(SCCF falls back to equal weights in 80–87% of runs)"]

Drill-down (Phases 4 and 4b)

flowchart TD
  P["each parent g with ≥ 3 eligible members"] --> GZ["parent score = cos(mean of members' updates, reference)"]
  GZ --> NULL["compare with 64 random groups of the same size<br/>→ parent z (permutation test)"]
  NULL --> F{"parent z < −2 ?"}
  F -->|"v1"| V1["members face a stricter cut this round (z < −1)"]
  F -->|"v2"| V2["member check: residual r_i = signal − reference;<br/>a_i = cos(r_i, mean of the other members' residuals)<br/>vs clients outside the parent → alignment z"]
  V2 --> E2["evidence uses min(z_i, −alignment z_i)"]
Parent score \(g = \cos(\tfrac{1}{|P|}\sum_{i\in P}\Delta_i,\ \text{ref})\), compared with 64 random groups of the same size: \(z_P = (g - \operatorname{med}\,\text{null}) / \max(1.4826\,\mathrm{MAD}\,\text{null}, 0.01|\operatorname{med}\,\text{null}|)\).
v2 member check: \(r_i = \text{signal}_i - \text{ref}\), \(a_i = \cos\big(r_i, \tfrac{1}{|P|-1}\sum_{j\in P, j\ne i} r_j\big)\), standardised against clients outside the parent.

Neither version was adopted. Honest members of a FedHEP parent are genuinely alike, so the member check also blames honest groups.

Comparison methods

No defense: FedAvg (one ResNet-9, weighted average of all uploads) and undefended FedHEP. Multi-Krum (authors' setting): score each update by the summed squared distance to its n − f − 2 nearest others, and average the 3 best. Phase 5 puts each established rule in FedHEP's Global step, on weight updates; the parents run SCCF over the clients the rule accepts.

flowchart LR
  U["weight updates Δ_1..Δ_n<br/>(BatchNorm buffers: coordinate median)"] --> MED["Median: per coordinate median"]
  U --> TM["Trimmed mean: per coordinate,<br/>drop 3 largest + 3 smallest, average"]
  U --> BU["Bulyan (f = 3): repeated Krum picks 9,<br/>then per coordinate average 3 nearest the median"]
  U --> FL["FLAME: HDBSCAN on cosine distances of models<br/>keep majority cluster → clip to median norm S<br/>→ average + N(0, (0.001·S)²)"]
  U --> FT["FLTrust: server trains on 100 clean images → g0<br/>trust = ReLU(cos(Δ_i, g0)), rescale to |g0|,<br/>trust-weighted average"]
  MED --> G["new Global"]
  TM --> G
  BU --> G
  FL --> G
  FT --> G
  BU -. "accepted clients" .-> PAR["parents: SCCF over accepted members"]
  FL -. "accepted clients" .-> PAR
  FT -. "accepted clients" .-> PAR
\[ \textbf{Trimmed mean:}\ \ \text{step}_k = \frac{1}{n-2b}\sum_{j=b+1}^{n-b} \Delta_{(j),k}\ \ (b = 3) \qquad \textbf{FLTrust:}\ \ \text{step} = \frac{\sum_i \mathrm{ReLU}(\cos(\Delta_i, g_0))\,\frac{\|g_0\|}{\|\Delta_i\|}\Delta_i}{\sum_i \mathrm{ReLU}(\cos(\Delta_i, g_0))} \] \[ \textbf{FLAME:}\ \ S = \operatorname{med}_i \|\Delta_i\|, \quad \text{step} = \frac{1}{|A|}\sum_{i\in A} \Delta_i \min\Big(1, \frac{S}{\|\Delta_i\|}\Big) + \mathcal{N}(0, (0.001\,S)^2) \] \[ \textbf{Bulyan:}\ \ n \ge 4f+3;\ \text{pick } \theta = n - 2f \text{ by repeated Krum, then per coordinate average the } \beta = \theta - 2f \text{ nearest the median} \]

Attacks

With \(w\) the round-start Global model and \(\Delta_i\) the attacker's honestly trained update: \[ \text{sign flip: } w - 1.5\,\Delta_i \qquad \text{gradient ascent: } w - 5\,\Delta_i \qquad \text{random noise: } w + \mathcal{N}(0, 2^2) \] \[ \text{ALIE: } w + \mu - z\,\sigma, \quad z = \Phi^{-1}\!\Big(\frac{n-s}{n}\Big),\ s = \Big\lfloor\frac n2 + 1\Big\rfloor - m \quad (z = 0.43 \text{ for } n = 15, m = 3) \] \[ \text{Min-Max: } w + \mu - \gamma\,\sigma, \quad \gamma = \max\Big\{\gamma : \max_j \|\mu - \gamma\sigma - \Delta_j\| \le \max_{j,k}\|\Delta_j - \Delta_k\|\Big\} \]
  • Label flip: train on label C − 1 − y instead of y.
  • Backdoor (BadNets): a 3×3 white corner patch on 50% of the attacker's images, relabelled as class 0. "Boosted" scales the update ×3.
  • ALIE: μ and σ are the per-weight mean and standard deviation of the attackers' own honest updates, chosen to sit inside the honest spread.
  • Min-Max: uses the honest updates' statistics and goes as far as possible while never looking further from anyone than two honest clients do from each other.

Metrics

Per round, with flagged set F (left out or isolated), attackers A and honest clients H: \[ \text{precision} = \frac{|F\cap A|}{|F|}, \qquad \text{recall} = \frac{|F\cap A|}{|A|}, \qquad \text{false-isolation rate} = \frac{|F\cap H|}{|H|} \]

Accuracy is pooled over all honest clients' own test images, each predicted by its own personalised ensemble. Wrongly isolated honest clients are included; attackers are not scored. Backdoor success is the share of triggered test images, not originally of class 0, that the model labels class 0.
